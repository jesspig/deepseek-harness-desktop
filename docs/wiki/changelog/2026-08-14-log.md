## 2026-08-14-18 dsh-TUI 社区参考调研落档,修正 desktop profile bundles 组合

- 新增 [research/dsh-tui-reference.md](../research/dsh-tui-reference.md)(Research):调研 ccch1mneyyy/dsh-TUI(npm 包 `dsh-cc-tui`,302 stars,官方公众号收录):
  - 形态验证:官方只有 Web UI,社区以「纯 Cordis 插件 + profile」补位 TUI,零核心改动——与桌面端同一扩展路径;
  - `dsh plugin --profile <name> add <pkg>` 机制:自动初始化 profile(bundles 首层 `@deepseek-ai/dsh-base`)→ profile 内 `pnpm add` → 检测 `dsh.bundle.patch` 自动追加为 bundle 层;
  - 发布模式:`files: [lib, cordis.patch.yml, ...]`(构建产物进 npm 包,安装无需构建)、`exports` 暴露 `./cordis.patch.yml`、`peerDependencies: @deepseek-ai/cordis ^4.0.1`;
  - 版本情报:依赖 `@deepseek-ai/*@^0.1.0-rc.6`,与 implementation-plan 的 npm 核实一致;
  - Windows 封装 `dsh-cc.cmd`(支持 `--resume`);对桌面端的四点启示(形态验证 / 分发双路径 / desktop-bundle 可薄 / bundles 组合佐证)。
- 修正 bundles 组合矛盾:desktop profile 必须包含 `@deepseek-ai/dsh-web-app`(webServer / 浏览器插件名册 / `dsh web:` URL 就绪行的提供者,官方 `web` 模板即 `[dsh-base, dsh-web-app]`);同步修正 6 处表述:`README.md`、`AGENTS.md`、`index.md`、`modules/desktop-profile.md`(含组合说明)、`modules/desktop-bundle.md`、`project/implementation-plan.md`(仓库布局 + M0.3 方案 A)。
- 更新 `index.md`(新增「研究」章节)、`log.md`(同一天合并摘要)。
